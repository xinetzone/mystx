主题设计方案
============

+----------+-----------------------------------------------------------+
| 决策     | 结论                                                      |
+==========+===========================================================+
| 基座     | ``pydata-sphinx-theme``\ （唯一父主题）                   |
+----------+-----------------------------------------------------------+
| SBT 角色 | 参考实现，代码级借鉴，不进依赖                            |
+----------+-----------------------------------------------------------+
| 首版能力 | 全书侧栏、页眉按钮、边注（+ 单列阅读 CSS）                |
+----------+-----------------------------------------------------------+
| 选项策略 | PST 原名 + ``book_*`` 新键；不设 SBT 别名                 |
+----------+-----------------------------------------------------------+
| 兼容层   | 不做（无历史配置需要兼容）                                |
+----------+-----------------------------------------------------------+
| 构建后端 | ``scikit-build-core`` +                                   |
|          | ``setuptools-scm``\ （\ ``cmake=false``\ ，纯 Python      |
|          | 不需要 CMake）                                            |
+----------+-----------------------------------------------------------+
| 依赖     | ``sphinx>=8.2`` +                                         |
|          | ``pydata-sphinx-theme``\ ；MyST/Notebook 由站点自行选择   |
+----------+-----------------------------------------------------------+

+----------+-------------------------------------+------------------------------+
| 项       | 取值                                | 理由                         |
+==========+=====================================+==============================+
| Python   | ``>=3.11``                          | 与 PST 要求一致，不额外抬高  |
+----------+-------------------------------------+------------------------------+
| Sphinx   | ``>=8.2,<10``                       | 与 PST 的约束对齐            |
+----------+-------------------------------------+------------------------------+
| 父主题   | ``pydata-sphinx-theme>=0.24,<0.25`` | 本机 3.14 环境解析到         |
|          |                                     | 0.24.0，已做 PoC 验证        |
+----------+-------------------------------------+------------------------------+
| 构建后端 | ``scikit-build-core>=0.11`` +       | 产物                         |
|          | ``setuptools-scm>=8``               | ``py3-none-any``\ ；版本取自 |
|          |                                     | git tag，无需手写            |
+----------+-------------------------------------+------------------------------+
| 版本起点 | tag ``v0.0.1``                      | ``setuptools-scm``           |
|          |                                     | 去掉前缀后推导发行版版本     |
|          |                                     | ``0.0.1``                    |
+----------+-------------------------------------+------------------------------+
| 打包内容 | ``src/mystx`` 全量（含 ``theme/**`` | ``wheel.packages``           |
|          | 资源）                              | 递归收集，非 ``.py``         |
|          |                                     | 文件随包发布                 |
+----------+-------------------------------------+------------------------------+
| 自有代码 | ``src/mystx/`` 约 6 个模块          | 见「方案」页 4.6 节          |
+----------+-------------------------------------+------------------------------+
| 文档构建 | ``doc/`` 新建                       | 不复用任何既有站点结构       |
+----------+-------------------------------------+------------------------------+

**不引入清单**\ （与 ``tests/chaos/`` 划清边界）：

+----------------------------------+------------------------------------------------------------------+
| 类别                             | 不引入的理由                                                     |
+==================================+==================================================================+
| TOML 配置加载器 / presets        | 主题默认值应写在 ``theme.toml``\ ，站点覆盖走                    |
|                                  | ``html_theme_options``\ ；再加一层配置源会让"取值从哪来"不可判定 |
+----------------------------------+------------------------------------------------------------------+
| 字体注册管线                     | PST 已提供字体变量；站点字体属于站点配置，不属于主题             |
+----------------------------------+------------------------------------------------------------------+
| ``myst_compat`` 钩子             | 兼容层针对旧解析器行为；新主题直接对齐 myst-parser 5.x           |
+----------------------------------+------------------------------------------------------------------+
| 并行守卫                         | PST 声明 ``parallel_read_safe/write_safe``\ ，主题无需重复       |
+----------------------------------+------------------------------------------------------------------+
| 版本切换器封装                   | PST 已有 ``switcher`` + ``switcher.json``\ ，不重写              |
+----------------------------------+------------------------------------------------------------------+
| ``ext/gallery``\ 、GitHub        | 文档扩展与主题职责无关                                           |
| 统计卡片                         |                                                                  |
+----------------------------------+------------------------------------------------------------------+
| ``tasks/`` 文档任务              | 构建任务属于站点，不属于主题包                                   |
+----------------------------------+------------------------------------------------------------------+
