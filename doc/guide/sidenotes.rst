侧栏注释
========

边注把脚注搬到引用点右侧的留白里，读者不必来回跳转。mystx 提供三种"出边"方式，
它们都由 ``book_use_sidenotes`` 控制脚注部分，``{margin}`` 指令则始终可用。

.. list-table::
   :header-rows: 1
   :widths: 24 18 58

   * - 方式
     - 是否编号
     - 语法与适用内容
   * - 边注
     - 是
     - 普通脚注 ``[1]_``；行内内容
   * - margin note
     - 否
     - 脚注正文以 ``{-}`` 开头；行内内容
   * - ``{margin}`` 块
     - 可带标题
     - 指令；块级内容（代码、图片、表格）

打开开关
--------

.. code-block:: python

   html_theme_options = {
       "book_use_sidenotes": True,
   }

默认关闭。关闭时脚注仍是页尾注释，页面里不会出现边注结构；``{margin}`` 指令
不受影响。

边注
----

在正文里写普通脚注，引用处会变成上标编号，正文出现在右侧留白——像这样：边注适合
放补充说明与术语解释\ [1]_。同一个段落不要超过两条，否则右侧会拥挤\ [2]_。

margin note
-----------

脚注正文以 ``{-}`` 开头时，编号会被去掉，只留一个符号\ [3]_。适合"可读可不读"
的旁注。

块级留白
--------

需要放代码、图片、表格时用 ``{margin}``：

.. code-block:: rst

   .. margin:: 旁注标题

      块级内容，可以放任意指令。

.. margin:: 这是一个 margin 块

   块级内容走 ``aside.margin``，宽屏进右侧留白，窄屏折回正文并带左边线。

没有标题时省略参数即可：

.. code-block:: rst

   .. margin::

      没有标题的旁注。

也可以给任意支持 ``:class:`` 的指令追加 ``margin``：

.. code-block:: rst

   .. note::
      :class: margin

      这个提示框会出现在右侧留白。

窄屏与打印
----------

窄屏下边注默认收起，点击编号展开；margin 块回到正文流，位置仍在引用点附近。
打印时所有边注回到正文，只保留一份内容。因此不要把主线论证放进边注。

实现要点
--------

- 变换在 ``FootnoteToSidenote`` （post-transform，优先级 1，仅 html）里完成：
  匹配引用与脚注、生成节点、删除原脚注。
- 引用位于提示框、表格等容器内时，正文会被复制一份提到容器之前，容器内保留
  ``d-n`` 副本供窄屏展开。
- 结构是 ``label`` + ``input[type=checkbox]``，不依赖 JavaScript。

.. [1] 边注是行内内容，不能放代码块与列表。
.. [2] 超过两条时，右侧留白会被切得很碎。
.. [3] {-}margin note 没有编号，视觉上只剩一个可点击的符号。
